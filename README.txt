
ALPRIFT Decision Support System
===============================

Study Area:
Shabestar Plain

Main Components:
A - Aquifer Media
L - Land Use
P - Pumping
R - Recharge
I - Aquifer Thickness Impact
F - Fault Distance
T - Water Table Decline

Main Scenario Variables:
T - Groundwater decline
P - Pumping
R - Recharge

Additional Sensitivity Variables:
A, L, I, F and ALPRIFT weights

Important Rule:
Baseline data must never be overwritten.

Main outputs:
- Baseline SVI
- Scenario SVI
- Delta SVI
- Scenario vulnerability rank
- Area statistics
